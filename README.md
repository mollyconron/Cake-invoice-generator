#Cake Invoice Generator

A Python project I’m developing for my cake business.

The program takes a customer’s cake size, sponge, icing and filling choices and generates a PDF invoice.

It uses the Open Food Facts Prices API to retrieve egg prices and calculate the cost of eggs needed for each cake. It also saves prices in a CSV file and uses Matplotlib to plot changes over time.

I’m planning to extend the cost calculations to other ingredients as I develop the project.
